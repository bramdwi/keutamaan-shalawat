# Keutamaan Shalawat ﷺ (Fadhail Shalawat)

Aplikasi Web Progresif (**Progressive Web App - PWA**) Islami yang menyajikan risalah lengkap kitab monumental ***Fadhail Shalawat*** karya **Quthbul Aqthab Syaikhul Hadits Maulana Muhammad Zakariya Kandhlawi Muhajir Madani** *(wafat 1402 H)*.

Didigitalisasi secara lengkap dari Halaman 1 hingga Halaman 218 dengan tipografi Arab berharakat indah, transliterasi Latin, terjemahan Bahasa Indonesia, takhrij hadits, syarah faedah, dan dukungan penuh **100% Offline-First**.

---

## 🌟 Fitur Utama

- 📖 **Struktur Lengkap Kitab:**
  - **Mukadimah:** Profil Kitab, Khutbah Penulis, Wasiat Guru Syaikh Syah Muhammad Yasin Neginawi, Panggilan Batin Madinah.
  - **Bab I:** Fadhilah & Keutamaan Sholawat secara Umum (23 pasal, QS. Al-Ahzab: 56, QS. An-Naml: 59, 10 Hadits Utama, Tuntunan Salam di Raudhah, Takmilah 44 Keutamaan As-Sakhawi).
  - **Bab II:** Fadhilah Khusus Bacaan Sholawat Tertentu (21 pasal, Sholawat Ibrahimiyah, Sholawat Hari Jumat, Wasilah Adzan, Panduan Bermimpi Nabi ﷺ, **Kumpulan 40 Hadits Sholawat & Salam Zadus Sa'id**, Waktu Mustahab & Makruh).
  - **Bab III:** Ancaman & Peringatan bagi yang Enggan Bersholawat (7 pasal, Doa Mimbar Jibril AS, Gelar Orang Paling Kikir, Sikap Kasar *Jafā'*, Majelis Sia-sia, Kunci Hijab Doa, Panduan Shalat Hajat).
  - **Bab IV:** Faedah Beraneka Ragam, Masalah Fiqih, dan Adab Sholawat (7 pasal, Hukum Fardhu Seumur Hidup, Dalil Gelar *Sayyidina* & *Maulana*, Keutamaan Ahli Hadits Menulis Sholawat, 8 Fatwa Kitab *Ad-Durrul Mukhtar*).
  - **Bab V:** 50 Kisah dan Hikayat Teladan Para Pengamal Sholawat (Sholawat Munjiyat, Latar Belakang Dala'ilul Khairat, Syafaat di Alam Kubur, Shirath, Rambut Suci Balkh, Ratapan Sayyidina Umar, Mukasyafah Sayyid Ahmad Ar-Rifa'i 555 H).
  - **Khatimah:** Untaian Syair Mathnawi Parsi Maulana Abdurrahman Jami', Qashidah Bahariyyah Maulana Muhammad Qasim Nanotwi, Catatan Penutup Penulis 1384 H, Ulasan Penerbit, dan Bisyarah Ruhiyah.
- 🎚️ **Personalisasi & Kenyamanan Membaca:**
  - 3 Pilihan Tema Warna: **Sepia (Warm Paper)**, **Malam (Dark Emerald)**, dan **Terang (Clean White)**.
  - Pilihan Font Arab: *Amiri (Klasik Naskh)* dan *Scheherazade New (Modern)*.
  - Slider Ukuran Huruf Arab (Kecil s/d Jumbo) & Huruf Latin.
  - Toggle tampil/sembunyikan Teks Arab, Transliterasi, Terjemahan, dan Syarah.
- 📿 **Tasbih Digital Shalawat:** Dilengkapi getaran haptic saat menyentuh layar di smartphone, pilihan lafadz sholawat ma'tsur, target hitungan (33, 100, 1000, Bebas), dan tombol reset.
- 🔍 **Pencarian Cepat Seluruh Kitab:** Instant cross-chapter search berdasarkan kata kunci, nomor hadits, nama sahabat, kisah, atau topik fiqih.
- 🔖 **Bookmark & Auto Last Read:** Menyimpan pasal/kisah favorit dan otomatis mengingat posisi bab terakhir yang dibaca.
- 📲 **Salin & Bagikan ke WhatsApp:** 1-klik untuk menyalin teks hadits/kisah beserta artinya atau membagikannya ke keluarga dan grup ta'lim.
- ⚡ **PWA & Offline-First:** Ukuran super ringan (<130 KB gzipped) dan dapat di-install langsung ke layar utama smartphone (*Add to Home screen*).

## 🛠️ Teknologi yang Digunakan

- **Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite 6](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **PWA Engine:** [vite-plugin-pwa](https://vite-pwa-org.netlify.app/) (Workbox caching offline)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Arabic Fonts:** Google Fonts (*Amiri* & *Scheherazade New*)

## 🚀 Menjalankan Secara Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/bramdwi/keutamaan-shalawat.git
   cd keutamaan-shalawat
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:5173/`.

4. **Build untuk produksi:**
   ```bash
   npm run build
   ```
